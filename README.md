# Movies Project (Docker + PostgreSQL)

## Описание проекта
Django-приложение для управления базой данных фильмов. 
В рамках лабораторной работы проект был упакован в Docker-контейнеры, а база данных переведена с SQLite на PostgreSQL.

## Функционал
- Добавление фильмов с выбором хранилища: база данных или файл (JSON/XML).
- Проверка на дубликаты при сохранении в базу данных.
- Просмотр данных из обоих источников (БД и файлы).
- AJAX-поиск по базе данных (без перезагрузки страницы).
- Редактирование и удаление записей (с валидацией вводимых данных).
- Адаптивный интерфейс на базе Bootstrap 5.

## Инструкция по запуску через Docker

1. Убедитесь, что у вас установлен Docker Desktop.
2. В корне проекта создайте файл `.env` (пример переменных окружения описан в коде settings.py).
3. Выполните сборку образов и запуск контейнеров:
   ```bash
   docker compose up -d --build
