# 🎬 Фильмы — JSON / XML

Django-приложение для импорта и экспорта данных о фильмах в форматах **JSON** и **XML**.

## 📋 Возможности

- ✅ Добавление фильма через HTML-форму с валидацией полей
- ✅ Сохранение данных в файл `.json` или `.xml`
- ✅ Загрузка файлов на сервер с серверной проверкой на валидность
- ✅ Автоматическое удаление невалидных файлов
- ✅ Просмотр содержимого всех файлов на отдельной странице
- ✅ Безопасные имена файлов (UUID) — защита от path traversal
- ✅ Сообщения об успехе / ошибках через Django messages

## 🚀 Установка и запуск


# 1. Клонировать репозиторий
git clone https://github.com/chuenkovaksenia08-ctrl/laba3.git
cd laba3

# 2. Создать виртуальное окружение
python -m venv .venv

# Активировать (Windows)
.venv\Scripts\Activate.ps1

# Активировать (macOS/Linux)
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Применить миграции
python manage.py migrate

# 5. Запустить сервер разработки
python manage.py runserver

Ссылка на сайт:  http://127.0.0.1:8000/
